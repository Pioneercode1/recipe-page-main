# Frontend Mentor - Recipe page solution

This is a solution to the [Recipe page challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/recipe-page-KiTsR8QQKm). Frontend Mentor challenges help you improve your coding skills by building realistic projects.

## My process
### Built with
- Semantic HTML5 markup.
- CSS custom properties.
- Mobile-first workflow.
- I chose a font that is easy to read, attractive, and reflects the theme of food and cooking.
- I used some browser extensions that calculate sizes.

### Useful resources
- [page-ruler](https://www.example.com) - I use it sometimes to find out the dimensions of width and height.
